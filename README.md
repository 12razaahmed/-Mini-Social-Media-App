# VibeStream - Mini Social Media App

Welcome to **VibeStream**, a modern, responsive social media feed built with pure HTML, CSS, and JavaScript.

## Features

### Core Functionality
- **Authentication**: Sign up and Login (simulated with LocalStorage).
- **Create Posts**: Share your thoughts and image URLs.
- **Feed**: View posts in a clean, glassmorphism-styled feed.
- **Interactions**: Like and Delete posts.
- **Search & Filter**: Search posts by content/author and sort by Latest, Oldest, or Popularity.

### Bonus Features
- **Dark/Light Mode**: Toggle between a sleek dark theme and a vibrant light theme.
- **Edit Posts**: Update your content after posting.
- **Persistence**: All data (users, posts, theme) is saved to your browser's LocalStorage.
- **Responsive Design**: Works beautifully on mobile and desktop.

## How to Run

1. Simply open `index.html` in your web browser.
   - You can double-click the file in your file explorer.
   - Or use a local server (e.g., Live Server in VS Code) for the best experience.

## Technologies Used
- HTML5
- CSS3 (Variables, Flexbox, Grid, Glassmorphism)
- JavaScript (ES6+, DOM Manipulation, LocalStorage)
- FontAwesome (Icons)
- Google Fonts (Outfit)

## Project Structure
- `index.html`: Main structure.
- `style.css`: All styling and theming.
- `app.js`: Logic for auth, posts, and state management.
